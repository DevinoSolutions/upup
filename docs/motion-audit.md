## 5. Tokens PR plan (landed in #592)

**Where the tokens live.** Landing only. Do not touch `packages/tailwind-config` (the uploader ships `--upup-fx-*` there; landing does not consume that package, and a landing token there would leak into published CSS).

1. `app/globals.css`, in the existing `:root` block (`:11-16`), add: `--motion-dur-fast:120ms; --motion-dur-base:180ms; --motion-dur-slow:240ms; --motion-ease-out:cubic-bezier(.16,1,.3,1); --motion-ease-in:cubic-bezier(.4,0,1,1);` Prefix `--motion-*` makes a collision with `--upup-fx-*` impossible (those only exist on `.upup-scope`). Tailwind is v3 here, so there is no built-in `--ease-out` to shadow, but keep the `--motion-` prefix anyway.
2. `tailwind.config.ts` `theme.extend`: `transitionDuration: { fast:'var(--motion-dur-fast)', base:'var(--motion-dur-base)', slow:'var(--motion-dur-slow)' }`, `transitionTimingFunction: { 'motion-out':'var(--motion-ease-out)', 'motion-in':'var(--motion-ease-in)' }`, plus keyframes + `animation` entries for the spot-treatments: `motion-enter` (opacity, translateY(6px)), `motion-enter-down` (opacity, translateY(-8px)), `motion-fade` (opacity), `motion-panel` (opacity, scale .98, translateY(8px)). Remove (or leave and rule out) the dead 0.5 s / 20 px `fadeIn`/`fadeInUp`/`bounce-slow` (`tailwind.config.ts:25-45`) so nobody reaches for them. Use these via `motion-safe:animate-motion-enter`.
3. **Global reduced-motion net** at the bottom of `app/globals.css` (outside `@layer`, so `!important` is the only override needed). The brief's literal net would break two things here, so scope it:
