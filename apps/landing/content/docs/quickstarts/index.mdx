---
title: Framework quickstarts
description: Add the upup file uploader to React, Vue, Svelte, Angular, Vanilla JS, Preact, or Next.js — one install per framework, the same features everywhere.
---

Pick your framework and get a working uploader in a few minutes. Every
quickstart starts in client mode, so there is no server package to run; each
framework ships the same drag-and-drop UI, cloud-drive sources, camera, and
resumable uploads. For the concepts behind them, see
[Getting Started](/docs/getting-started/).

- [React](/docs/quickstarts/react/) — `@useupup/react`, the canonical upup UI,
  for React 19 apps.
- [Vue](/docs/quickstarts/vue/) — `@useupup/vue` for Vue 3 apps.
- [Svelte](/docs/quickstarts/svelte/) — `@useupup/svelte` for Svelte 5 apps.
- [Angular](/docs/quickstarts/angular/) — `@useupup/angular`, a standalone
  component for Angular 19+.
- [Vanilla JS](/docs/quickstarts/vanilla/) — `@useupup/vanilla`, framework-free,
  for any page.
- [Preact](/docs/quickstarts/preact/) — `@useupup/preact`, a `preact/compat`
  re-export of the React UI.
- [Next.js](/docs/quickstarts/next/) — `@useupup/next`, client UI and server
  handlers in one install.
